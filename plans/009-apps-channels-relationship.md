# 009 软件选择 × 推送渠道 关系澄清

> 用户反馈：两个页面关系混乱，难以理解。
> 依据 apple-design：Wayfinding（每个屏幕回答“我在哪、东西去哪”）+ Grouping（把相关的控制放在一起）。

## 现状：两条独立轴，唯一的连接点藏得很深

真实的消息路由（`PerAppRouteResolver.resolve`）：

```
一条消息到达
  → 软件选择（App 规则）：发不发？过滤谁？长什么样（模板）
  → 推送渠道（全局目标）：发到哪？主渠道（或开多渠道后全部渠道）
  → Bark 绑定（连接两轴的唯一桥梁）：
      该 App 绑定了任意 Bark → 全局目标里的 Bark 被「挤掉」，只发绑定的 Bark + 非 Bark 渠道
      没绑定 → 正常走全局目标
```

UI 层面的混乱点：

| # | 问题 | 表现 |
| --- | --- | --- |
| C1 | 绑定关系单向可见 | 渠道行只有「已绑定 N 个 App」，看不到是哪 N 个、点不进；规则编辑页完全看不到「这条规则发到哪里」 |
| C2 | 绑定 UI 与渠道卡分离 | `BarkBindingCard` 是页面底部独立的 SectionCard，离对应的渠道行很远 |
| C3 | 「发到哪里」两个地方控制 | 渠道页的「主推送渠道」单选 vs 高级设置的「多渠道同时发送」开关，同一概念分两处 |
| C4 | 命名没回答用户的问题 | 「软件选择」看不出它是「转发的来源」；「推送渠道」看不出它和 App 的关系 |
| C5 | 绑定语义不直观 | 「绑定后这些 App 的 Bark 推送只发到这个 Bark」——“挤掉”行为没有任何 UI 提示，用户以为是“额外发送” |

## 方案 A（推荐）：绑定并入渠道卡 + 规则页显式路由 + 渠道归属收敛

改动集中在两个页面，零数据迁移。

**A1 渠道页：一个渠道一张卡，绑定内嵌**
- `BarkBindingCard` 并入渠道列表行：Bark 渠道行内直接展开「发送范围」——
  - 未绑定：`发送范围：全部应用（默认）`
  - 已绑定：`发送范围：仅微信、短信（2 个）` + 「管理」按钮进绑定选择
- 删除页面底部独立的绑定 SectionCard（C2 解决）
- 绑定 UI 里加一句挤掉语义提示：「绑定后，这些 App 只发到这个 Bark，不再发主渠道里的 Bark」（C5 解决）

**A2 规则编辑页：新增「发送渠道」只读卡**
- 在 App 规则编辑页顶部（转发设置卡之下）加一张卡：
  - `默认：主渠道「Bark 手机」`（或多渠道开启时显示「全部启用渠道」）
  - 若该 App 有绑定：`指定 Bark：Bark 公司 · Bark 平板`
  - 尾部 TextButton「管理绑定」→ 跳推送渠道页（或直接弹绑定选择弹窗，与 R2 交互模式一致）
- 规则页终于能回答“这个 App 的消息去哪”（C1、C4 解决一半）

**A3 渠道归属收敛：多渠道开关挪到渠道页**
- 「多渠道同时发送」从高级设置搬到推送渠道页顶部（与主渠道单选同卡）：
  - 关 = 主渠道单选（现状）；开 = 全部启用渠道
- 高级设置只剩失败重试（C3 解决）
- DataStore 字段不动，零迁移

**A4 命名微调**
- 设置页行名：「软件选择」→「转发来源（软件选择）」，副标题已有「N 个 App 启用转发」
- 渠道页副标题改为回答关系：「这些渠道决定所有 App 的消息发到哪里；个别 App 可单独指定 Bark。」

## 方案 B（激进，备选）：路由矩阵页

新增「路由总览」二级页：表格/列表按 App 维度展示 `App → 渠道` 的最终解析结果（直接调 `PerAppRouteResolver.resolve`），每行可点进规则编辑页。
优点：路由一目了然；缺点：又一个入口层级（与 008 收敛方向相悖），且读多写少。
→ 不推荐作为主方案，可作为 A 落地后的可选增强。

## 方案 C（保守，最小集）

只做 A2 + A4：规则编辑页加「发送渠道」只读卡 + 命名微调。
改动最小（~60 行），但 C2/C3/C5 仍在。适合不想动渠道页结构时。

## 推荐

**方案 A**（A1–A4 全做）。预估改动：MainActivity 渠道页重排 ~80 行、规则编辑页 +1 卡 ~40 行、高级设置 -1 卡、README/CHANGELOG 同步。编译+单测+lint 验证；`PerAppRouteResolver` 逻辑不动，现有单测不受影响。

## 真机验收点

1. 绑定 Bark 后，规则编辑页能看到指定 Bark；渠道行显示「发送范围：仅 X、Y」
2. 绑定卡里的挤掉提示可见
3. 多渠道开关出现在渠道页，开关后主渠道单选态正确切换
4. 高级设置只剩失败重试
