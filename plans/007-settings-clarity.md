# 007 · 设置页直观化（状态直读 + 入口收敛 + 分组重排）

- 严重度：MED（不坏功能，但持续增加认知成本）
- 规模预估：2–3 文件 ~150–200 行；零 Migration、零新 DataStore 字段
- 状态：✅ implemented（决策：B 全做 + 4 组；编译+单测+lint 通过，2026-09-23；真机 feel check 待验）

## 设计原则（emil-design-eng）

1. **一眼三答**：进来应立刻知道 ①现在什么状态 ②该去哪改 ③影响谁（全局/按应用，徽标已做）。
2. **高频路径最短**：转发相关（App/模板/免打扰/记录）进设置即达；低频（SIM/关于/许可）下沉。
3. **不加装饰动效**：设置页每天看几十次 → 状态徽标与摘要全部静态（动效决策框架第 1 步）；转场沿用 001 的 AnimatedContent 不动。
4. **状态非纯色**：徽标文字承载语义，颜色仅辅助（延续 SettingScope 约定）；48dp 触摸目标不回退。

## 方案

### A. 状态直读（P0，核心收益）

1. `SettingNavRow` 加可选尾部插槽（默认 `null`，全部现有调用点零改动），免打扰行改为：副标题恒为描述「跨午夜时段与关键词例外」，尾部 `StatusBadge` 显示 `已开启 22:00–07:00` / `未开启`（P2）。
2. 动态副标题（数据全部来自已存在的 Flow/字段，UI 不直连 SQL、不加网络）：
   - 推送渠道 → `已配置 N 个 · 主渠道 X`；未配置 → `尚未配置，先添加 Bark/飞书/钉钉`（Danger 徽标「未配置」）
   - 软件选择 → `N 个 App 启用转发`（`dao.rulesFlow()` 页面级订阅，同 Records/PushChannel 既有模式）
   - 消息模板 → `默认：{模板名} · 自定义 N 个`（DataStore 默认模板 id + `templatesFlow` 自定义计数）
   - 记录与隐私 → `保留 {retentionLabel} · {隐私模式label}`（复用 `retentionLabel`，隐私 label 从 `:1059` 内联 when 提取为 helper）
   - 备份/后台/教程等低频行保持静态描述（没有值得直读的状态）。
3. 图标按「一行一图标、语义唯一」重映射（`material-icons-extended` 已是依赖）：外观 Palette、推送渠道 Notifications、软件选择 Apps、消息模板 Description、免打扰 Schedule、记录与隐私 History、备份 Save、后台 PlayCircle、SIM SimCard、高级 Tune、教程 MenuBook、版本 Update、GitHub Code、反馈 BugReport、关于 Info（P3）。

### B. 入口收敛（P1，解决 P4–P6）

1. **模板一个入口**：一级「消息模板」页扩为「全局默认模板选择（现状）+ 自定义模板库入口（进现 AdvancedTemplates 页）」；删除一级与高级设置里的重复行，`SubPage.AdvancedTemplates` 路由保留、只换进入路径。
2. **规则一个入口**：删除高级「关键词过滤与应用独立规则」行；「软件选择」页头部加「批量管理规则」入口进 `Rules` 页。软件选择成为规则域唯一入口。
3. **记录与隐私升一级**：从高级设置提升为一级行（全局徽标），副标题直读状态；高级设置删除该卡。
4. 高级设置收敛为「影响所有渠道行为的开关」：风险提示 + 多渠道同时发送 + 失败自动重试；确认弹窗文案同步改为只描述这些内容（P7）。

### C. 分组重排（P0 仅换序，不动任何路由）

推荐 4 组（备选 3 组，见决策点）：

```
转发设置   软件选择(按应用) · 消息模板(全局) · 免打扰(全局) · 记录与隐私(全局)
推送与数据 推送渠道(全局) · 备份与恢复(全局)
应用       外观(全局) · 后台运行 · SIM 卡管理(全局)
高级设置   区域入口（确认弹窗保留）
帮助与关于 使用教程 · 更新日志 · 版本更新 · GitHub · 反馈 · 关于（不变）
```

理由：按任务频次排序，SIM 从 C 位下沉；组名即扫描锚点。

### D. 明确不做

- 不动 DataStore/Room/备份格式（零 Migration）；不清任何用户配置。
- 不删 `SubPage` 路由、不引入新依赖（仍不用 NavHost）。
- 不动首页（暂停开关已在首页状态卡）；不加设置页概览卡（与首页重复）。
- 无新增动画；高级确认弹窗保留。
